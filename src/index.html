Networking 101

Selamat Datang, Guys!

Ini adalah simulasi jaringan dari tujuhlima.my.id.
Semua materi mulai dari kabel fisik hingga *Load Balancer* sudah dirangkum di sini.

1. Media Transmisi (Ethernet & Wi-Fi)

Untuk menghubungkan dua perangkat, kita butuh media. Ethernet menggunakan kabel fisik (tembaga/fiber), sedangkan Wi-Fi menggunakan gelombang udara. Keduanya memiliki tugas yang sama: mengantarkan sinyal data.

2. Jaringan Lokal (MAC Address & Switch)

Setiap perangkat memiliki identitas perangkat keras unik bernama MAC Address. Ketika banyak perangkat ingin terhubung di satu lokasi, kita menggunakan Switch. Switch membaca MAC Address tujuan dan mengirimkan data hanya ke perangkat yang tepat di jaringan lokal.

3. Jaringan Luas (IP Address & DHCP)

Agar bisa berkomunikasi di jaringan luar, PC membutuhkan IP Address. Jika terhubung ke Router yang mengaktifkan DHCP Server, IP Address diberikan otomatis dan bisa berubah-ubah (Dinamis). Namun, jika DHCP dimatikan, kita harus mengisi IP Address sendiri secara manual (Statis) agar PC mendapatkan IP yang tetap.

4. Keluar Jaringan (Subnet & Router)

Subnet menentukan seberapa besar ukuran sebuah jaringan lokal. Jika datamu harus dikirim ke luar Subnet (jaringan lain yang berbeda IP), perangkatmu akan mengirimkannya ke "pintu keluar" atau Default Gateway, yang merupakan sebuah Router. Router bertugas menjembatani komunikasi antar jaringan (misal: meneruskan paket dari IP 192.168.1.x menyeberang ke 10.0.0.x, dan sebaliknya).

5. Mencari Jalan (Routing, OSPF, BGP)

Bagaimana Router tahu jalan menuju tujuan? Mereka menggunakan Routes (Rute). Protokol *routing* (seperti OSPF atau BGP) akan mencari jalan paling efisien. Pada animasi di atas, data (titik kuning) pintar memilih jalur bawah (1-4-5) yang lebih pendek ketimbang harus memutar lewat jalur atas yang lebih panjang.

6. Tes Koneksi (Ping & ICMP)

Untuk mengecek apakah jalur jaringan berfungsi, kita gunakan perintah Ping. Ping mengirimkan paket kecil menggunakan protokol ICMP, mengetuk perangkat tujuan, dan menunggu balasan untuk memastikan perangkat tersebut "hidup".

7. Cara Pengiriman (TCP vs UDP)

TCP memastikan setiap paket data tiba tanpa error (cocok untuk transfer file/teks). Jika hilang, akan dikirim ulang. Sedangkan UDP mengirim data terus menerus tanpa peduli ada yang hilang (cocok untuk *Video Call* atau *Game* karena lebih cepat).

8. Pintu Aplikasi (Ports & Firewall)

Satu komputer bisa menjalankan banyak aplikasi bersamaan. Port adalah angka yang mengarahkan data ke aplikasi yang tepat (Misal Port 80 untuk Web). Firewall bertugas seperti satpam, memblokir Port atau lalu lintas mencurigakan agar tidak bisa masuk ke server (seperti Port 22 yang ditolak), sementara lalu lintas yang aman (Port 80) diizinkan lewat.

9. Enkripsi (TLS & VPN)

TLS (Transport Layer Security) mengenkripsi jalur komunikasi tertentu, sementara VPN (Virtual Private Network) mengenkripsi seluruh aktivitas perangkat dari ujung ke ujung. Seperti yang terlihat pada animasi di atas, enkripsi mengubah data "Hello" menjadi teks acak yang tidak dapat dimengerti oleh hacker yang mengintip, dan hanya dikembalikan menjadi data asli setelah sampai di tujuan yang benar.

10. Buku Telepon (DNS)

Komputer berkomunikasi menggunakan IP Address berupa angka. Karena manusia sulit menghafal deretan angka tersebut, DNS (Domain Name System) berfungsi sebagai buku telepon. Prosesnya ada 2 tahap: Pertama, PC bertanya ke Server DNS untuk menerjemahkan google.com menjadi IP Address. Kedua, setelah mendapat IP Address tersebut barulah PC mengakses Server Google sesungguhnya untuk menampilkan halaman web.

11. Web & Skala Besar (HTTP & Load Balancer)

HTTP/HTTPS adalah cara komputermu meminta halaman web dari server. Jika sebuah website didatangi jutaan orang, satu server akan mati seketika. Solusinya adalah Load Balancer, sebuah alat di depan server yang membagi-bagi antrean pengunjung ke banyak server di belakangnya secara bergiliran (seperti yang terlihat pada animasi data kuning di atas).
